# MYTHTOPPLACE Prototype Specification

## A. Landing/Lobby
- Brand MYTHTOPPLACE.
- Hero sederhana, premium, dark.
- Kartu game: Mobile Legends, PUBG, Clash of Clans, Roblox.
- CTA menuju top-up.

## B. Checkout
- Pilihan game.
- Pilihan nominal.
- Input Game ID.
- Pilihan pembayaran: QRIS, DANA, MANDIRI.
- Ringkasan harga.
- Tombol buat order.

## C. Status
- `PENDING` — order dibuat dan menunggu pembayaran.
- `PROCESSING` — pembayaran/pekerjaan telah masuk proses.
- `COMPLETED` — admin telah menyelesaikan verifikasi.
- `CANCELLED` — order dibatalkan/timeout sesuai aturan bisnis.

## D. Admin
- Daftar order.
- Detail order.
- Status.
- Aksi verifikasi.
- Audit trail.

## E. Visual direction
- Premium sederhana.
- Mobile-first.
- Kontras tinggi dan tipografi bersih.
- Jangan menambah animasi berat tanpa alasan.
